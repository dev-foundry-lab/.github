# 🔥 Dev Foundry Lab

### Learn. Build. Experiment. Improve.

Welcome to **Dev Foundry Lab**, a hands-on software engineering laboratory dedicated to learning through real-world projects.

We explore modern technologies, experiment with software architectures, and turn technical concepts into working applications.

---

## 🚀 What We Do

- **Learn** — Explore programming languages, frameworks, and engineering principles.
- **Build** — Develop real-world applications through structured workshops.
- **Experiment** — Test technologies, tools, and architectural approaches.
- **Share** — Document knowledge, source code, and practical experiences.
